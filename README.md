# clear-writing

Компактный навык для ИИ-агентов: писать понятные статьи, отчёты, объяснения и тексты презентаций без потери смысла.

Навык помогает объяснять сложное занятому читателю, который не знаком с контекстом. Подходит для написания с нуля и содержательной редактуры готового текста. Инструкции написаны на русском.

## Что делает

- Начинает с главной мысли и её значения для читателя.
- Заменяет канцелярит и абстракции обычными словами и конкретными объяснениями.
- Объясняет необходимые термины и сокращения.
- Показывает, что происходит, на что это влияет и, когда уместно, что можно сделать.
- Учитывает формат: статья, отчёт или презентация.
- Сохраняет факты, числа, единицы, отрицания, условия, исключения и степень уверенности.

## Установка

Скачайте репозиторий. Создайте папку `clear-writing` в каталоге навыков вашего агента и скопируйте в неё [SKILL.md](SKILL.md). Для работы нужен только этот файл; скриптов и дополнительных зависимостей нет.

| Агент | Для одного проекта | Для всех проектов пользователя |
|---|---|---|
| Codex, локальная среда | `.agents/skills/clear-writing/SKILL.md` | `~/.agents/skills/clear-writing/SKILL.md` |
| Claude Code, локальная среда | `.claude/skills/clear-writing/SKILL.md` | `~/.claude/skills/clear-writing/SKILL.md` |

`~` означает домашнюю папку пользователя. В других агентах используйте каталог, предусмотренный их поддержкой Agent Skills.

Пути сверены 3 ноября 2026 года по [документации Codex](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) и [документации Claude Code](https://code.claude.com/docs/en/skills#choose-where-skills-load). Правила облачных сред могут отличаться от локальных.

## Как вызвать

Назовите навык в запросе:

```text
Используй clear-writing. Объясни эту техническую тему простыми словами
для руководителя, который не знаком с контекстом. Объём — до одной страницы.
```

```text
Используй clear-writing. Отредактируй отчёт: убери канцелярит,
объясни термины, сохрани цифры, условия и оговорки исходника.
```

```text
Используй clear-writing. Подготовь текст пяти слайдов для самостоятельного
чтения: по одной основной мысли на слайд с необходимыми пояснениями.
```

Агент с автоматическим выбором навыков также может вызвать его по просьбе «пиши понятно», «объясни человеческим языком», «без жаргона, ИИ-терминов и сокращений» или «убери канцелярит». Условия выбора описаны в поле `description` файла `SKILL.md`.

## Пример редактуры

Условный пример.

**До:**

> В случае временной недоступности сервиса отправка сообщений может быть выполнена с задержкой.

**После:**

> Если сервис временно недоступен, сообщения могут отправляться с задержкой.

Фраза стала проще. Условие и неопределённость сохранились: задержка возможна при недоступности сервиса, а не обязательна всегда.

## Границы навыка

Навык задаёт правила работы с текстом. Он не содержит инструментов для создания файлов презентаций или оформления документов. Сверка редактуры с исходником не заменяет независимую проверку фактов.

Проверка формата `SKILL.md` выполнена. Сравнительная оценка качества текстов с навыком и без него пока не проводилась; совместимость установки не проверялась запуском отдельных клиентов.
